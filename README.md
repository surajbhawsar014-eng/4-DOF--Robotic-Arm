4-DOF Robotic Arm

A 4-Degree-of-Freedom robotic arm built using SG90 servo motors and an Arduino board, controlled through a Python application using Pygame.

Project Overview

This project demonstrates the integration of Python programming, hardware control, and robotics. A connected controller provides input to a Python application, which communicates the required movements to the Arduino-based robotic arm.

Technologies Used

- Python
- Pygame
- Arduino
- SG90 Servo Motors

Features

- Four-degree-of-freedom robotic arm
- Controller-based movement
- Python-based controller input handling
- Arduino-based servo motor control

Project Structure

- "python/" — Python controller application
- "arduino/" — Arduino code for servo control
- "images/" — Project images

Setup and Installation

1. Install Python.
2. Install the required Python dependencies.
3. Connect the controller to your computer.
4. Upload the Arduino sketch to your Arduino board.
5. Connect the servo motors according to your circuit design.
6. Run the Python application.

Refer to the source code for the actual pin assignments and controller configuration.
